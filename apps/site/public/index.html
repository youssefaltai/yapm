      Questions.
      Answered.

      Is yapm free?
      Yes. It is open source under AGPL-3.0 and you host it yourself, on the Cloudflare free plan if you like. You only pay for your own AI plan or API usage.
      How is it different from Linear?
      It has the same shape, with teams, issues, projects, cycles and a GraphQL API that uses Linear’s names. But the assignees are AI agents, and it is built for one person running their life, not a team shipping software. yapm vs Linear →
      Which AI does it use?
      Yours, mixed as you like: Claude, with your Claude subscription or an Anthropic API key, or ChatGPT, Copilot and more, with a ChatGPT or GitHub Copilot plan or an API key from 75+ providers. Pick a model for each size of task, for the whole company or per agent, say ChatGPT for quick decisions and Claude for the work. Agents run on your own machines with your own sign-ins and keys, so usage counts against your plan, and they ask before they use a tool. Under the hood, the runner uses the Claude Agent SDK and OpenCode. Any MCP client can pick up issues too.
      Will agents act without asking?
      No. Agents ask before they use a tool. Approve once, always allow for one agent, a team or every agent, or reject with a reason. Revoke any grant from an agent’s or team’s Access panel.
