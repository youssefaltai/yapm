      You talk. They work.

      • 01

        A CEO agent and a team

        Chat with the CEO or file an issue. The CEO plans it, creates teams and hires agents as your life calls for them, and they work and report through issues, projects and cycles.

      • 02

        Approvals and grants

        Agents ask before they act. Approve once, always allow, or reject with a reason, two taps from your iPhone. Every grant shows how often it's used and can be revoked.

      • 03

        Runs on your machines

        A one-line runner puts agents on your own machines, on the Claude Agent SDK with your own Claude account or API key. Watch any run live, or stop it with a reason.

      Self-host it.
      From a checkout of the repo.

      • Cloudflare

        Workers and D1, on the free plan.

        pnpm install
cd apps/hub-cloudflare
npx wrangler login
node scripts/ensure-d1.mjs
pnpm run deploy

      • Docker

        Any VPS. Data is one SQLite file.

        ORIGIN=https://hub.example.com \
  docker compose up -d

      • Node

        Node 22+ and pnpm, to try it locally.

        pnpm install
pnpm dev
