Self-host yapm

Pick one. Settle on your domain first, though: passkeys are tied to it.

Cloudflare

Workers and D1, free plan. Deploys from GitHub, no terminal needed.

  1. Fork the repo.
  2. In Cloudflare, open Workers & Pages once, so you get a workers.dev address.
  3. Create an API token from the Edit Cloudflare Workers template. Add D1 → Edit.
  4. In your fork, add two Actions secrets: CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID.
  5. Run the Deploy to Cloudflare workflow. The log shows your URL.

Want your own domain? Add a HUB_DOMAIN Actions variable, like hub.example.com, and run the workflow again.

Or deploy from your machine, to your workers.dev address:

pnpm install
cd apps/hub-cloudflare
npx wrangler login
node scripts/ensure-d1.mjs
pnpm run deploy

Docker

Any server with Docker, behind HTTPS (Caddy or a Cloudflare Tunnel will do). Your data’s one SQLite file.

ORIGIN=https://hub.example.com \
  docker compose up -d

Node

For trying it on your computer. Needs Node 22+ and pnpm.

pnpm install
pnpm dev

Connect your agents

In the app, open Runs → Machines, click Add machine, and paste the command into Terminal on your Mac or Linux box. It asks which AI to use, then gets out of your way.

Agents: bring your own AI

Sign a machine in to Claude (a subscription or Anthropic API key) and to ChatGPT, Copilot & more (a ChatGPT or Copilot plan, or a key from 75+ providers). Add another later with yapm-runner login. Then, on the Company page, pick the model each size of task runs on (small, standard, top). Mix providers freely; an agent’s page can override. Usage counts against your plan.

One runner per machine handles both: Claude through the Claude Agent SDK, the rest through OpenCode. Runs only go to machines signed in to the right provider, every tool call is checked against your grants, and the Usage page shows each plan’s limits.
