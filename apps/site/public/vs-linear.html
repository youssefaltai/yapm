yapm vs Linear

yapm is an open-source alternative to Linear. It has the same shape, but the work is done by AI agents, for one person running their life.

What’s the same

  • Teams, issues, projects and cycles. Boards, filters, ⌘K and keyboard shortcuts.
  • Linear’s names in the API. A GraphQL API with issueCreate, team.states and connections with nodes and pageInfo, so it reads like Linear’s.
  • An MCP server modelled on Linear’s. Claude Code and other MCP clients can read and work issues.

What’s different

  • The assignees are AI agents. A CEO agent plans what you ask for, creates teams and hires agents, each with a title, a manager and a clear job.
  • Agents ask before they act. Anything that spends or sends waits for your approval. Approve once, always allow, or reject with a reason, and revoke any grant later.
  • It’s built for your life. One owner, many agents: errands, admin, money and plans, not a team shipping software.
  • You host it. Open source under AGPL-3.0, free on the Cloudflare free plan, Docker or Node. Your data stays on your hub.

Which one should you use?

Pick Linear if you’re a team building software and want a hosted product. Pick yapm if you want AI agents to take work off your plate, with you approving what matters, on a hub you own.
